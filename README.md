# CS203 - Network Security (UC Irvine)

Course materials and study resources for **CS203: Network and Computer Security** at the University of California, Irvine (Spring 2025). This repository collects the lecture slides, lecture recordings, sample exams, and supplementary notes covering core topics in modern network and computer security.

## Course Info

- **Course:** CS203 - Network Security
- **Instructor:** Gene Tsudik
- **Term:** Spring 2025
- **University:** University of California, Irvine

## Topics Covered

Based on the lecture slides, the course covers:

- Security background and foundations
- User authentication and password security (including honey passwords)
- Kerberos authentication
- SSL/TLS
- IPsec
- Firewalls
- Network attacks and defenses
- Anonymity systems
- Spam
- Access control
